# CQD Research Toolkit: DLCP 17.2 / MFIA 1.4 / PLOT 2.1.1

CQD 광검출기 연구의 측정·분석·시각화를 지원하는 Windows x64 프로그램 3종입니다.

- **DLCP Research Studio V17.2**: DLCP/EIS 데이터 처리, 공통 회로 피팅과 결과 진단. 테스트 73개 및 EXE 합성 데이터 자가검사 통과.
- **MFIA DLCP Control 1.4**: Zurich MFIA 조건별 DLCP 자동 취득. 테스트 74개 통과/1 skip. 빌드 환경의 EXE GUI 검증은 Tcl 접근 오류로 미완료입니다. 사용자 보고에 610포인트 약 75분 취득 사례가 있습니다.
- **Measurement Plot Studio 2.1.1**: CSV 오버레이와 PNG/SVG/PDF 저장. 테스트 33개, GUI·내보내기 및 EXE 자가검사 통과. EXE와 `_internal` 폴더를 함께 유지하세요.

ZIP 전체를 압축 해제한 뒤 사용하세요. Python 설치는 필요 없습니다. 원본 연구 데이터와 장비 접속 정보는 배포하지 않습니다. 자동 분석의 물리적 해석과 장비 조건은 연구자가 확인해야 하며, 테스트 통과가 모든 장비 조건의 검증을 뜻하지 않습니다.

이번 ZIP은 기존 실행파일을 변경하지 않고 필수 리소스·사용 안내·검증 요약만 포함하도록 다시 구성했습니다. 실행파일 ZIP 무결성 확인은 `SHA256SUMS.txt`를 사용하세요. MFIA 1.5 원격 모니터링 개발본은 포함하지 않았습니다.
