# 화면과 출력 이미지의 출처

## DLCP 분석 GUI: 발표에 포함된 실제 실행 화면

![DLCP 개발 과정 GUI](images/dlcp_ui_presentation_20260907.png)

- 출처: `9.7_DLCP_실측EIS_최종.pptx`, 슬라이드 3에 포함된 원본 이미지.
- 창에 표시된 버전: DLCP Research Studio v13. 개발 과정을 보여주는 과거 실행 화면이며 최신 V17.2 화면으로 표시하지 않습니다.
- 표시 기능: CSV·소자 설정, C–Vac 피팅, Bias별 Summary와 저장 흐름.
- PPT에서 이미지 바이트를 그대로 추출했으며 UI·데이터를 재생성하지 않았습니다. 화면 안 수치는 당시 분석 예시이고 최신 버전의 추출 정확도를 입증하는 자료가 아닙니다.

## 포함하지 않은 자료

MFIA 발표 화면에는 장비 ID, 내부 네트워크 주소와 개인 저장 경로가 포함돼 있어 공개용에서 제외했습니다. 이번 작업의 최신 EXE 화면 촬영은 외부 텔레메트리 연결에 대한 자동 승인 검토에서 차단되어 완료하지 못했습니다. 최신 화면을 촬영했다고 표기하지 않습니다.

`SCREENSHOT_PROVENANCE.json`에 이미지별 출처·버전 구분과 파일 해시를 기록했습니다. 원본 발표 PPT 전체와 실측 CSV는 업로드하지 않습니다.
